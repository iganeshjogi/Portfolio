# Ganesh Jogi — Data Analyst Portfolio

## Files
- `index.html` — portfolio content
- `style.css` — responsive layout and light/dark theme styles
- `script.js` — theme toggle, mobile navigation, automatic footer year
- `assets/profile.jpg` — profile photo used in the navigation header
- `assets/resume.pdf` — resume used by the View and Download buttons

## Run locally
1. Open this folder in VS Code.
2. Start `index.html` with Live Server, or open it directly in a browser.

## Updating later
- Profile photo: replace `assets/profile.jpg` and keep the same filename.
- Resume: replace `assets/resume.pdf` and keep the same filename.
- Certifications: edit the links and titles in the Certifications section of `index.html`.
- Projects: update each project card and repository URL in `index.html`.

## Notes
- Certificate images have been removed; each certification card opens its verification link.
- GitHub project URLs use `https://github.com/iganeshjogi/` plus the repository names visible in your screenshot. Please test each link before publishing.
- The public email address is `ganeshjogi2004@gmail.com`; change it in `index.html` if needed.
